# Today I Learned: 2026-10-15

## REA: MCP Server untuk Reverse Engineering via AI Agent

### Ringkasan
Protokol Model Context Protocol (MCP) kini mulai merambah ranah analisis biner tingkat rendah melalui tools seperti **REA** (Reverse Engineering Agent). Tool ini mengintegrasikan kapabilitas disassembler dan decompiler langsung ke antarmuka AI coding agent melalui standard MCP server dan CLI.

### Poin Kunci
1. **Dukungan Target Luas**: Menganalisis binary native, aplikasi berbasis Electron/Node.js yang dipaket, hingga rekaman lalu lintas jaringan (*network captures*) tanpa memerlukan repositori source code asli.
2. **Pergeseran Paradigma**: Agen AI tidak lagi terbatas pada *forward engineering* (menulis fitur atau membaca repositori git terbuka), tetapi kini mampu melakukan *vulnerability research*, audit dependensi biner terkompilasi, dan analisis protokol tertutup secara semi-otonom.
3. **Standarisasi Tooling**: Menggunakan MCP sebagai lapisan abstraksi mempermudah integrasi berbagai mesin disassembler/debugger langsung ke agen generik tanpa perlu modifikasi core model.

### Implikasi
- Keamanan software closed-source akan diuji lebih cepat oleh perkakas audit berbasis agen.
- Praktik hardening biner, enkripsi konfigurasi di sisi client, dan arsitektur zero-trust pada API endpoint semakin krusial karena biaya analisis biner menurun drastis.
